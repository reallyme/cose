# Buffa option descriptors

`ext/options.proto` is an unchanged copy from ReallyMe Buffa 0.1.3,
`buffa-proto-options/protos/buffa/ext/options.proto` in
[reallyme/buffa](https://github.com/reallyme/buffa). It is distributed under the
included Apache 2.0 license.

SHA-256: `544906883afa7fa900628393cf191a2a77ce17f4b5a8a71f445c59d6beb227da`.

Buf uses this import to interpret typed native-adapter options. It is not a
generation target or part of the runtime API. The protobuf package includes
the descriptor and its license so downstream schema imports remain resolvable.
